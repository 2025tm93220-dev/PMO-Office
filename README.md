# PMO-Office

This repository is used to manage project planning and inventory information using Git and GitHub.

## Files

### Inventory.txt
Contains inventory details such as:
- Laptops
- Monitors
- Keyboards

### Planning.txt
Contains project planning information:
- Project Start Date
- Project End Date

### Budget.txt
Contains project budget details:
- Hardware Budget
- Software Budget

## Git Operations Performed

- Repository Creation
- Clone Repository
- Add Files
- Commit Changes
- Push Changes to GitHub
